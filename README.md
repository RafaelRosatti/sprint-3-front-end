# 📱 MoodShot

## Inteligência que entende cada momento.

O **MoodShot** é um projeto desenvolvido pela **Apexxon Consultoria** como proposta de inovação para a câmera do próximo smartphone **Jovi**.

A ideia é transformar a fotografia em uma experiência mais prática e inteligente, utilizando **Inteligência Artificial** para adaptar a câmera ao contexto escolhido pelo usuário.

## 🚀 O que é o MoodShot?

Antes de tirar uma foto, o usuário escolhe o tipo de momento que está vivendo, como:

* 🎉 Festa
* 📚 Estudo
* ✈️ Viagem
* ❤️ Encontro

A câmera então utiliza esse contexto para auxiliar na captura e facilitar o compartilhamento.

Entre os principais recursos estão:

* Enquadramento e filtros com IA
* Configuração baseada no contexto
* Sugestão de legendas
* Preparação da publicação para redes sociais
* Interface simples e intuitiva

## 📸 Experiência

O funcionamento do MoodShot é dividido em quatro etapas:

```text
Câmera
   ↓
Escolha do momento
   ↓
Preview + legenda
   ↓
Compartilhamento
```

## 💻 Tecnologias utilizadas

O desenvolvimento da Landing Page utiliza:



## 🎨 Design

A interface segue a identidade visual definida para o projeto, utilizando principalmente:

* Fundo escuro
* Azul como cor predominante
* Laranja para destaques
* Roxo como cor complementar

O objetivo é transmitir uma estética relacionada à **tecnologia, inovação e Inteligência Artificial**.
